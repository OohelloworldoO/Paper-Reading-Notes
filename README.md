# Meeting

meeting 應該以「研究判斷」為核心，競賽只是研究或團隊工作的一部分。約 30–45 分鐘：

1. Paper 報告（約 20–25 分鐘）
   選一篇真正和目前題目有關、能影響下一步決策的 paper  
   報告順序：
   - 研究問題：作者想解決什麼，為何重要？
   - 核心方法：模型／實驗／資料怎麼設計？
   - 關鍵結果：只挑 1–3 個最重要的圖表或表格。
   - 批判：它的假設、限制、可能偏誤是什麼？
   - 對你們的意義：你們可採用什麼、不能直接套用什麼、下一步要驗證什麼。
     最後必須有一句自己的結論，例如：  
     這篇 paper 的方法可作為我們競賽的 baseline，但資料前處理假設與我們的情境不同；我建議先重現其核心流程，再比較是否加入我們的特徵。
2. 本週競賽進度（約 10 分鐘）用「目標 → 結果 → 解讀 → 下一步」：
   - 這週原定目標是什麼？
   - 實際完成什麼？有數據或可展示成果嗎？
   - 結果代表什麼？比預期好或差的原因？
   - 現在的主要風險或瓶頸？
   - 下週要交付什麼具體成果？
     例如：  
     本週完成 baseline，分數為 X；雖然比預期低，但錯誤主要集中在 A 類資料。下週會先驗證 B 特徵是否有增益，若無效就停止投入。
3. 團隊討論結果與需要教授決定的事（約 5–10 分鐘）
   只講已經有分歧、需要外部判斷的議題。每題用固定格式：  
   我們有 A 與 B 兩種方案。  
   A 的好處是＿＿，代價是＿＿。  
   B 的好處是＿＿，代價是＿＿。  
   團隊目前傾向＿＿，原因是＿＿。  
   想請老師判斷＿＿。
