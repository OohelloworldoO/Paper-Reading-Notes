# Compare

問題:`q`  
檢索文件:`D`  
已知標準答案:`a`

| Type        | 簡要                                                                                                                                                                        | 基本流程                                                                                              | 差異 |
| :---------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------- | :--: |
| RAG         | 檢索判斷哪些文件與問題相關、語言模型利用文件與自身能力形成答案。一般 RAG 不代表模型「沒有內部知識」，模型參數依然存在，只是基本流程沒有明確要求它先獨立回想，再與文件比較。 | user -> `q` -> 檢索`D` -> `q` + `D` 交給語言模型 -> response                                          |      |
| InstructRAG | 讓模型自己產生如何利用文件回答問題的說明(rationale)，再用這些說明教模型處理檢索雜訊(可以理解為答案與證據之間的推理說明)                                                     | 建立示範(那些文件有助於得到答案?如何支持答案?如果文件都沒有幫助，是否能由自身知識說明?) -> 回答新題目 |      |
| IDEAL-RAG   |                                                                                                                                                                             |                                                                                                       |      |
